# Getting Support for HeliOS

Need help using HeliOS? We're here to help!

## Before Requesting Support

Start with the documentation! The **[HeliOS Developer's Guide](/doc/HeliOS_Developers_Guide.pdf)** is your primary resource for understanding the HeliOS API, syscalls, and architecture. Most questions can be answered by consulting the guide.

## When to Request Support

Request support if:
- You've consulted the documentation and still need help
- You're encountering unexpected behavior but aren't sure if it's a bug
- You need guidance on how to implement a specific feature
- You have questions about HeliOS architecture or best practices

## How to Request Support

**[Submit a Support Request](https://github.com/heliosproj/HeliOS/issues/new/choose)** using the "Support Request" template.

### What to Include

To help us assist you effectively, please provide:

**Your Question:**
- **Clear description** - What are you trying to accomplish?
- **What you've tried** - What troubleshooting steps have you already attempted?
- **Relevant code** - Provide a minimal code sample (text format, **NOT screenshots**)
- **Error output** - Include compiler errors or serial output if applicable (text format, **NOT screenshots**)

**Environment Information:**
- **HeliOS version** - e.g., 0.5.0, develop branch, or specific commit hash
- **Hardware platform** - e.g., Arduino UNO, Teensy 4.1, STM32F429, ESP8266
- **Development environment** - e.g., Arduino IDE 2.0, PlatformIO, STM32CubeIDE, Keil µVision
